## 📖 Descripción

**PubBeerOnly** es una landing page profesional orientada al sector gastronómico y cervecero, diseñada con una estética moderna, fuerte identidad visual y enfoque comercial.

El proyecto está pensado para:

* Cervecerías artesanales
* Pubs
* Bares premium
* Restaurantes temáticos
* Marcas gastronómicas

---

## ✨ Features

* Diseño visual moderno
* Hero section de alto impacto
* Navegación clara y minimalista
* Secciones comerciales optimizadas
* Responsive Design
* Estructura preparada para conversión
* Estética premium enfocada en branding
